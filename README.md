# JAVA CAREER RACE — GitHub Pages + Tilda

Готовый статический проект. Сервер, npm, сборка и база данных не нужны.

## Содержимое
- `index.html` — страница с картой и интерфейсом игры
- `styles.css` — оформление
- `game.js` — механика игры и 92 дополнительных задания
- `questions.json` — полный банк из 920 записей (4 варианта, категория/уровень, ответ и разбор)
- `TILDA_T123.txt` — короткая вставка для Tilda
- `.nojekyll` — отключает обработку Jekyll

## Публикация в GitHub Pages
1. Создайте **публичный** GitHub-репозиторий с названием `java-career-race`.
2. Загрузите в его корень **содержимое этой папки**, а не папку целиком (Add file → Upload files → Commit changes).
3. Откройте репозиторий → Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите `main` и `/ (root)`, сохраните. Дождитесь публикации Pages.
5. Откройте `https://YOUR_GITHUB_USERNAME.github.io/java-career-race/` и убедитесь, что игра показывает карту и интервью.
6. В Tilda добавьте блок T123, вставьте содержимое `TILDA_T123.txt` и замените YOUR_GITHUB_USERNAME своим логином.
7. Опубликуйте страницу Tilda, проверьте игру на компьютере и смартфоне.

## Обновление вопросов
Отредактируйте `questions.json`, сохраните файл в том же репозитории. После публикации изменений игра прочитает новые данные (формат и **текущее условие загрузки ровно 920 записей** сохранены в game.js; при изменении количества поправьте проверку длины).

## Важно
- GitHub Pages — публичный хостинг: задания и правильные ответы будут доступны всем, кто откроет файлы или инструменты разработчика. Не используйте этот вариант для секретного/прокторингового тестирования.
- Автоматически созданные варианты ответов по многим вопросам нуждаются в экспертной проверке перед использованием для реального отбора кандидатов.
- Если игра открывается сама по себе, но не показывается в Tilda, проверьте наличие опубликованной GitHub Pages и отсутствие ограничений встраивания со стороны браузера/сайта.
- Размер iframe 980px можно изменить в T123; на мобильном может потребоваться больше высоты.
- GitHub Pages используется для статических файлов. Никакого API или хранения результатов игроков не предусмотрено.
